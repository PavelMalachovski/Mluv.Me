# Монтаж видео

Все скрипты лежат в `scripts/` рядом с этим файлом. Работа — в scratchpad
(или во временной папке), не в репозитории. Отвечай пользователю по-русски.

## Правила (всегда, если пользователь явно не отменил)

1. **Субтитры есть в каждом ролике.** Вшитые, по 2–3 слова, произносимое
   слово подсвечивается жёлтым. Плюс отдельный `.srt` рядом с роликом.
2. **Шкала времени есть в каждом ролике.** Полоса внизу кадра: жёлтая часть —
   сколько прошло, тёмная дорожка — сколько осталось до конца. Её рисует
   `finish.py` всегда; меняется только вид (`--bar-pos top`, `--bar-color`, `--bar-height`).
3. **Текст субтитров правит человек-редактор, то есть ты.** Распознавание
   ошибается в именах и брендах ("кот" вместо "Claude", "Копленький" вместо
   "CoPlanly"). Сверяй каждый островок со сплошным текстом, который печатает
   `transcribe.py`, и с контекстом разговора. Времена не трогай. Не уверен в
   имени — оставь лучший вариант и **спроси пользователя в итоговом ответе**.
4. **Просьбы из самого видео выполняются.** Если автор говорит в кадре
   "добавь вот сюда X" и показывает рукой — вставка X появляется **там, куда он
   показывает, и в момент, когда он это говорит** (см. «Вставки»).
5. **Формат 9:16, 1080×1920.** Вертикальный исходник — как есть; квадратный
   или горизонтальный — по центру на размытой копии самого кадра.
6. **Звук выравнивается** до громкости соцсетей (`loudnorm`); тихая запись
   с телефона — ещё и `--denoise`.
7. **Перед отправкой посмотри кадры** готового ролика (5–6 кадров в одну
   картинку через `hstack`): субтитры читаются, вставки не закрывают лицо,
   шкала видна. Звук на слух не проверить — так и скажи.
8. **Паузы режь, если просят или если ролик длинный и с запинками.** Если
   автор показывает рукой места для вставок — не режь без нужды: склейки собьют
   жесты. "В сомнении — оставь": лишний повтор стоит второго прогона, а потерянная фраза портит ролик.

## Шаг 0. Установка (один раз за сессию)

```sh
bash scripts/setup.sh          # в конце печатает MODEL=...
```

Ставит ffmpeg, шрифт Montserrat (кириллица), распознавание речи. Если
huggingface.co закрыт (облачные сессии Claude), скрипт сам берёт ту же модель
Whisper large-v3-turbo в формате ONNX из релизов sherpa-onnx на GitHub и
ставит обёртку `whisper-cli`. Значение `MODEL=` передавай дальше как `--model`.

## Шаг 1. Где взять видео

- Файл, загруженный в чат (`/root/.claude/uploads/...`), — основной путь.
- Несколько частей — передай их все в `edit_video.py` по порядку, он склеит.
- **Большой файл (больше ~30 МБ) — через черновик релиза GitHub** (до 2 ГБ). Создать
  релиз из сессии нельзя (403), поэтому пользователь делает его сам в Chrome:
  `https://github.com/<owner>/<repo>/releases/new` → тег (например `video-1`) →
  прикрепить файл в «Attach binaries» → **Save draft** (не Publish: черновик виден только
  соавторам). Затем: `gh api repos/<owner>/<repo>/releases --jq '.[]|{id,tag_name,draft,assets:[.assets[]|{id,name,size}]}'`
  и скачивание **через curl** (встроенный `gh` не идёт по редиректу на файлы релиза):
  `curl -sSL -H "Accept: application/octet-stream" -o src.mp4 https://api.github.com/repos/<owner>/<repo>/releases/assets/<id>`.
  Сверь размер с `size`. После монтажа попроси пользователя удалить черновик и тег —
  удалять релизы сессии тоже нельзя.
- Страница-загрузчик в артефакте (assets + db, куски по 19 МБ) работает в браузере, но
  **в приложении Claude на Android кнопка выбора файла не открывается** — не предлагай её
  как основной путь для телефона.
- Google Drive для видео НЕ подходит: коннектор (`download_file_content`)
  отдаёт файл base64 прямо в контекст, а 1 МБ видео — это ~1,3 млн символов;
  сам drive.google.com из облачной сессии закрыт. Проверь размер через
  `get_file_metadata` и попроси загрузить файл в чат (29 МБ проходили), при
  необходимости — сжать (отправить себе в WhatsApp/Telegram) или разрезать на части.
- Сначала посмотри видео: `ffprobe` (длительность, поворот), контактный лист
  кадров (`fps=1,scale=180:-1,tile=6x2`), сплошная расшифровка.

## Шаг 2. Черновой монтаж (паузы и оговорки)

```sh
python3 scripts/edit_video.py clip1.mp4 [clip2.mp4 ...] -o edited.mp4 --lang ru --model "$MODEL"
```

Режет тишину, фальстарты и повторы (остаётся последний дубль), никогда не режет
внутри слова. Прочитай вывод и `edited.takes.tsv` как сценарий: фраза, брошенная
и сказанная заново другими словами, режется повторным запуском с
`--cut A:B` (времена из tsv; повторно ничего не распознаётся). Настройки:
`--min-sil 0.35` — если монтаж «задыхается», `--noise 25` — шумная запись (порог тишины по умолчанию подбирается по громкости: тихая запись с телефона получает −40…−45 дБ),
`--pad 0.08` — обрезаются концы слов. `edited.srt` этого скрипта для субтитров
**не используй** (он дробится на обрывки) — субтитры делает шаг 3.

Резать не нужно — пропусти шаг, дальше подавай исходник.

## Шаг 3. Субтитры

```sh
python3 scripts/transcribe.py edited.mp4 -o subs.json --lang ru --model "$MODEL"
```

Пишет `subs.json` — `[{start, end, text}]` во времени ЭТОГО видео — и печатает
островки и сплошной текст. **Исправь `text` в `subs.json` руками** (правило 3).
Островков с речью можно объединять/делить, сохраняя `start`/`end` по краям.

## Шаг 4. Вставки (если автор просит или ролик просит украшения)

1. Найди момент и место: кадры с подписью времени вокруг слов «вот сюда»
   (`fps=4,drawtext=text='%{pts\:flt}'…,tile=6x2`), затем 1–2 полных кадра с
   сеткой (`drawgrid=w=108:h=192` на 1080×1920) — куда указывает палец.
   Вставка ставится рядом с пальцем, не на лицо, и не в верхние ~250 px и
   нижние ~350 px (там интерфейс Reels/TikTok).
2. Скопируй `scripts/overlay/example.json`, оставь нужные элементы, задай
   `t0` (секунда готового ролика, учитывая вырезанные паузы) и координаты.
   Типы элементов:
   - `bachata` — карточка с анимированной парой, танцующей бачату (`title`, `colors`);
   - `badge` — плашка-логотип «иконка + текст» (`text`, `colors`, `iconPaths`
     из SVG или `iconImage` — путь к PNG, `shineAt` — блик, `pulseAt` — пульс);
   - `sticker` — карточка с заголовком и текстом (`title`, `text`);
   - `image` — готовая картинка (`src`, `w`, `radius`).
   Общие поля: `t0`, `t1` (исчезнуть), `rot` (наклон). Нужен новый тип
   (другой танец, другой персонаж) — дорисуй функцию в `DRAW` в
   `overlay.html` по образцу `bachata`/`couple`.
3. Логотип продукта бери из настоящих файлов: репозиторий продукта
   (`list_repos` → клонировать, искать `icon`, `logo`, `*.svg`), сайт. Не
   выдумывай логотип реальной компании, которой нет у пользователя.
4. Генерация картинок через коннекторы (Gamma и др.) тратит кредиты
   пользователя и может быть недоступна — нарисовать кодом обычно надёжнее.
5. Рендер кадров (длительность = длина ролика + `--hold`):
   ```sh
   cd scripts/overlay && NODE_PATH=$(npm root -g) node render.js my.json 12.6 /path/frames
   # проверка отдельных моментов:  ... node render.js my.json 12.6 /tmp/test 4.5 9.6
   ```

## Шаг 5. Сборка

```sh
python3 scripts/finish.py edited.mp4 --subs subs.json -o final.mp4 \
    [--title "ЗАГОЛОВОК" --title2 "подзаголовок" --title-until 5] [--overlay /path/frames] [--hold 1] [--denoise]
```

Заголовок лучше держать первые 4–6 с (`--title-until`), чтобы он не спорил со вставками вверху кадра.
Делает 9:16, субтитры, шкалу времени, заголовок, вставки, стоп-кадр в конце
(`--hold`, вставки продолжают двигаться), затухание, выравнивание звука, и
пишет `final.srt`. Положение субтитров — `--sub-margin` (отступ от низа, px),
размер — `--sub-size`, слов на экране — `--words`.

## Шаг 6. Отдать результат

Отправь `final.mp4` и `final.srt` пользователю (SendUserFile). Кратко:
длительность до/после, что вырезано и почему, где и когда стоят вставки,
какие имена/слова в субтитрах ты не уверен(а) и просишь проверить.
Предложи правки: размер и место элементов, заголовок, цвет субтитров, стоп-кадр.

## Если что-то сломалось

- `whisper-cli` не найден / модель не качается → `bash scripts/setup.sh`.
- Субтитров нет совсем → в `transcribe.py` слишком строгий порог: `--noise -50`.
- Квадратики вместо букв → не скачался Montserrat; проверь `fc-list | grep -i montserrat`.
- `nothing kept` в `edit_video.py` → очень тихая запись: `--noise 25` (и проверь, что `--lang ru`).
- Вставки не рисуются → `npm i -g playwright`; браузер Chromium должен быть установлен.
